# packs

Bundles of skills, tools and hooks for a kind of system. A pack is a directory with a `pack.json`:

```json
{"name": "pmss", "description": "..."}
```

Every pack is always loaded (ADR-0006). Hermes shows the model only each skill's name and description and loads a skill's full text when it is used, so shipping every pack costs little. The agent's SOUL.md starts with what this machine allows (root, the seedbox platform), and each skill says when it applies. To leave a pack out, list it in `local/config.php` under `packs.disabled`; `root.disabled` also leaves out the `root` pack. Nothing is downloaded: git already shipped it. Anything every machine needs belongs in the core runtime (`pikkumies/`), not in a pack.

Pack layout (all optional): `skills/<name>/SKILL.md`, `tools/<target>/`, `hooks/<event>/<name>.php`, read-only lessons in `memory/`, `README.md`. Because every pack is loaded on every machine, write skills to check that they apply before acting (see `root/skills/server-admin`), and write hooks to decide from the tool call they receive.

How to write each part: [pikkumies/doctrine/SOP/make-a-skill-tool-hook-or-pack.md](../pikkumies/doctrine/SOP/make-a-skill-tool-hook-or-pack.md).

`INDEX.md` is generated by `pikkumies packs index`. Do not edit it by hand.
