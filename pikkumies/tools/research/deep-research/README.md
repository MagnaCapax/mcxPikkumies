# deep-research

Hermes has the parts for research but no loop that ties them together ([ADR-0021](../../../../docs/adr/0021-web-access-off-unless-configured.md)). This unit is that loop, written as a procedure the agent follows, in two parts. First, whenever no lesson settles a question, it searches wide and checks twice: one memory search, then subagents read the top hits side by side (one per source group, at most 4), a second round of subagents checks each answer against the cited text and this machine, a third round only for what was contradicted or missing, and a lesson is saved either way ([ADR-0041](../../../../docs/adr/0041-memory-metrics-save-reminder-and-wide-search.md)). Each subagent spends the user's credits; the caps (4 a round, 3 rounds) bound the cost. Second, the web: plan the sub-questions, search and read the web, keep every source in a numbered ledger, give wide sub-questions to subagents that must bring back exact quotes, weigh the sources by trust, answer with citations, and save the result to `memory/research/` so the next search finds it.

Nothing here fetches pages itself, and nothing leaves the machine unless the user configured a web backend. Pages that need a browser are not readable out of the box, because runtime downloads are off; the user can turn them on with `hermes.lazyInstalls`.
