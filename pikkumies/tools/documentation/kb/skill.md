# Knowledge base

1. **Memory first.** The memory skill's `search` covers the lessons, the wiki and the knowledge base together; run it first on a task.
2. **Then the knowledge base itself** when you need more of it: `search` with a few words gives up to 10 articles and the best paragraph of the top one. `list` is every article title.
3. **Read the article** at the path `search` prints. For policies, prices and terms it is the official source: quote it and give its address. Never state a policy from memory.
4. **Nothing found?** The memory search's notes list the provider's support pages; give the user that address for questions the knowledge base does not answer.
