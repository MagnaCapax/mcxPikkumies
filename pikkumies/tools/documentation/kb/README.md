# kb

Searches and lists the provider's knowledge base from the copy Pikkumies downloads to `~/pikkumies/local/docs-cache/<source>/`. On Pulsed Media that is the client area knowledge base (`pm-kb`, a public JSON export); on other providers it is their knowledge base where `config/documentationSources.md` marks it `kind: kb`. Add or switch sources in `~/pikkumies/local/documentationSources.md`. The same articles are also searched by the memory tool, together with the lessons.
