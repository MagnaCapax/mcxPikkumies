# wiki

Searches and lists the provider's wiki from the copy Pikkumies downloads to `~/pikkumies/local/docs-cache/<source>/`. On Pulsed Media that is the public wiki (`pm-wiki`, through the MediaWiki API, refreshed daily); on other providers it is their wiki or docs site where `config/documentationSources.md` marks it `kind: wiki`. Add or switch sources in `~/pikkumies/local/documentationSources.md` (see that file). The same pages are also searched by the memory tool, together with the lessons.
