# pikkumies-configure

Pikkumies' own settings, for people and for the agent: the agent's name, performance logging and telemetry, how long Hermes keeps ended sessions, which version updates follow, the model, the hooks, tool categories and skills, and the SSH hosts the agent may or must not reach ([docs/ssh.md](../../../../docs/ssh.md)). It also keeps the user's own rules for one tool or tool category (`note-add`, `notes`, `note-remove`), which reach that tool's skill or the category's rules from the next start ([ADR-0076](../../../../docs/adr/0076-local-notes-for-a-tool-or-category.md)). The agent makes the changes that tighten something when the user asks; changes that loosen something, cost credits or delete history go through the orchestrator's ask policy first (the `config-change` hook): the change runs when what the user asked for covers it, and otherwise is refused and reported ([ADR-0073](../../../../docs/adr/0073-no-questions-no-deferrals-one-reviewed-exception.md), [ADR-0101](../../../../docs/adr/0101-refuse-and-report-never-ask.md)); turning a safety layer off, the provider and the terms stay with the person ([ADR-0032](../../../../docs/adr/0032-settings-configure-skill-first-run-and-install-flags.md), [ADR-0059](../../../../docs/adr/0059-settings-tiers-free-asked-and-the-persons-own.md)). `USAGE.md` has the table of who makes which change; every change is logged with its old value, and the person's `pikkumies configure undo` shows the last one and sets it back, asking y/N on their own terminal first only when that is a change the person would be asked about.

The user settings can be given at install, so an install from a script asks nothing:

```sh
~/pikkumies/bin/pikkumies install --name=Helper --accept-terms --telemetry=off --perf-logging=on --retention-days=90 --channel=release
```

The agent's name is never asked: it is Pikkumies until the person renames it in a session ("call yourself X"), with this skill or with `install --name=`. The first interactive session on a terminal asks the person to accept the terms of service (https://pulsedmedia.com/terms.php) and privacy policy (https://wiki.pulsedmedia.com/index.php/Pulsed_Media_Privacy_Policy). Runs without a terminal (cron, scripts) are never asked and never blocked.
