# feedback

Sends Pulsed Media feedback from inside Pikkumies: what you say, plus the conversation you were having with the agent, so the problem can be seen as it happened.

You type `/feedback` and say what went wrong or what you want. The agent writes a draft and shows you its size, which session is attached and how the text starts. Common password and key forms are removed from the text and the conversation before the draft is saved; that catches the usual forms, not every secret, so read the draft before sending it. Besides your text and the conversation, the draft carries the Pikkumies, Hermes and PMSS version numbers, and the conversation carries the session's model, provider and working directory. When you send it, Pikkumies asks you first. The question opens with where it goes and what goes: your text, the conversation transcript (all of it, or its newest 1.5 MB when it was cut to fit) and system information, to Pulsed Media at pikkumies.mcx.fi; then the size, the file holding all of it, and how your text starts. The message is locked on your machine with Pulsed Media's public key, so the server that receives it cannot read it, and only Pulsed Media can; it is linked to your Pulsed Media account through your AI key. A sent draft is kept, marked sent, and never sent twice. If sending fails, the draft stays and the error says whether trying again later can help.

With approvals turned off (`pikkumies run --yolo`), or in an agent started by another agent, the agent cannot send feedback: nobody would be asked. It gives you the command to run in your own terminal instead. A `/yolo` typed inside a session cannot be seen by Pikkumies' hooks; then the question before sending is skipped, as Hermes skips every question.

The question before sending catches the agent's own and casual sends. It is a safety prompt, not a security boundary: an agent steered by text it reads could still run the sender some other way, as it could run curl. What it sends is sealed to Pulsed Media either way.

## Being asked now and then (off unless you turn it on)

Pikkumies can now and then ask, at the end of an answer, whether you want to send feedback about the session. It is off by default. At the first interactive start after this arrives it asks you once whether to turn it on (Enter means no, and it is never asked again); you can also ask the agent to turn it on, and then Pikkumies asks you to confirm. When it is on, the question comes only in your own session on a terminal (not in scheduled jobs, chat gateways, agents started by agents or under `--yolo`), after at least 4 messages from you, in about 1 session in 5, and at most once a week; these numbers are starting values. The question itself sends nothing: a yes starts the steps above, and the send still asks you first. Say "never ask again", or use the pikkumies-configure skill, to turn it off (`feedback.ask`). Each question adds about 70 tokens to that turn, on your credits ([hook](../../../hooks/system/feedback-ask/)).

It needs a Pulsed Media AI key (`~/.virsilipasKey`) and PHP with sodium. Hermes' own `/debug` is different: it uploads to a public paste site. For anything private, use `/feedback`, or `/debug local` to see the report without uploading it.
