# telemetry

A local-only history of diagnostic and health measurements, the way SMART history is kept for a drive: every time `system-status account`, `system-status health`, `storage stats` or a torrent client's `stats` verb runs, it also appends one small numeric record here, so a chart of quota, memory, traffic or torrent counts over time can be drawn later. See [ADR-0086](../../../../docs/adr/0086-local-only-telemetry-history-for-diagnostics-and-health-runs.md) for the decision and why it is a plain JSON Lines history rather than a database.

Records live at `local/state/telemetry/<source>/YYYYMMDD.jsonl`, one UTC day per file, kept forever by default; `prune --keep-days N` deletes older files on request. `list` shows what is on disk and `series <source> <field>` returns the numbers bucketed by hour or day, ready for a chart; `record` is how the four tools above add a line and is not meant to be called for its own sake.

The `hooks/trace/usage-count` hook writes here too, after every tool call: how many times a Hermes tool, a skill or a Pikkumies unit's verb ran, and how often it succeeded ([ADR-0087](../../../../docs/adr/0087-tool-skill-and-verb-usage-counts-kept-on-this-machine.md)), so the question "how many times was X used" can be answered without Hermes' own `/insights`, which keeps its count inside `state.db` -- a database PHP cannot always open and whose schema Pikkumies does not own. `usage [--kind tool|skill|unit] [--human]` reads it back, sorted by how often each thing ran.

Nothing here is sent anywhere, and it stops recording entirely with `privacy.perfLogging` off (`pikkumies-configure`), the same setting [ADR-0041](../../../../docs/adr/0041-memory-metrics-save-reminder-and-wide-search.md) uses to keep memory-search metrics on this machine only. `privacy.telemetry` is a different, still-unused setting reserved for a future external sender (AGENTS.md, [ADR-0032](../../../../docs/adr/0032-settings-configure-skill-first-run-and-install-flags.md)); this tool does not read it, because nothing it writes ever leaves the machine.
