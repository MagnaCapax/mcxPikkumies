# catalog

Answers "what does this plan cost, is it on sale, what does it include" from Pulsed Media's public product feed, so the agent reads a few lines instead of the whole 95 KB feed. It reads only: it needs no key and orders nothing; a question to buy gets the plan's order link. If the feed cannot be read it refuses rather than give an old figure ([ADR-0111](../../../../docs/adr/0111-plan-catalog-tool.md)).
