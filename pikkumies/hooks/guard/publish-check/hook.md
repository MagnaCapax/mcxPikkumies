---
name: publish-check
event: pre_tool_call
description: Before a git push or a gh issue, pull request, gist or release goes to a public place, checks what goes out for passwords, keys, tokens and credential files; on a hit it blocks once with the lines masked, the agent takes the value out itself, and the same call again runs only when what the user asked for covers it (ADR-0083, ADR-0101).
failClosed: true
timeout: 10
---
Reads `terminal` commands only (`PublishTargets.php`, words split by `../ssh-connect/SshWords.php`). A `git push` is checked when its remote is on github.com, gitlab.com, codeberg.org or bitbucket.org (an `~/.ssh/config` Host alias read through its HostName) and the repository is not private (`gh repo view --json visibility`, 4 s; no answer counts as public); a push anywhere else, and ssh, scp and rsync, are never looked at. A gh `issue create|comment`, `pr create|comment` or `release create` is checked the same way for its repository (`-R`, else the directory's), a `gist create` always. What is read (`PublishScan.php`, 4 s): the commits the remote does not have (all reachable ones when it has no remote-tracking branches), their messages, added lines and file names; for gh the title, body, notes and the files it publishes. A line `Redact::secrets()` changes is a hit, shown masked; so is a file named like a credential file (`.env`, `*.pem`, `*.key`, `*.p12`, `*.pfx`, `id_rsa`..., `credentials`, `.netrc`). On a hit, or when something could not be read, the call is blocked once with the lines, and the agent takes the value out itself and publishes again; running the same call again (marker `local/state/publish-check/`, 7 days) is a question with `kind` `send` and `rule_key` `pikkumies-publish:<id>`, so the ask policy runs it only when what the user asked for covers publishing it, else refuses it ([ADR-0073](../../../../docs/adr/0073-no-questions-no-deferrals-one-reviewed-exception.md), [ADR-0101](../../../../docs/adr/0101-refuse-and-report-never-ask.md)). Fails closed ([ADR-0083](../../../../docs/adr/0083-check-before-publishing.md)).
