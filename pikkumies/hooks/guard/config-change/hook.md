---
name: config-change
event: pre_tool_call
description: Asks the user in Hermes' approval prompt before the agent makes a settings change that loosens something, costs credits, stops scheduled jobs or deletes session history, and before any edit of local/config.php or of the files that decide what the agent may change.
failClosed: true
timeout: 3
---
Reads `tool_name` and `tool_input`. A terminal command that is exactly `php <this Pikkumies' pikkumies-configure.php> set <key> <value>` (the path absolute or `~/`) is judged by the configure tool's own plan against the defaults and `local/config.php` (`ConfigureChange::plan`, [ADR-0059](../../../../docs/adr/0059-settings-tiers-free-asked-and-the-persons-own.md)): a change in the asked tier gets `approve`, the message naming the key, the old and new value and what that direction does, `rule_key` `pikkumies-config:<sha256 of key, old and new>`, so an "always" answer covers that change each time it recurs and never another; a free change or the person's own gets no opinion (the tool makes or refuses it, and `Config::set` refuses the person's for every caller). Asked, with the whole command and a hash of it: `pikkumies-configure` followed by `set` in any other form; a terminal command, `execute_code` code or `process_manage` input naming a key with an asked direction (from `ConfigureTiers::RULES`) next to the word `set` or `apply`; `Config::set`/`acceptTerms` and `ConfigureChange`/`ConfigureSettings` `apply`/`set`/`skills` as a call, a callable string or an array; setting `PIKKUMIES_CONFIG`; `write_file` or `patch` (its `path`, or the `Update`/`Add`/`Delete File:` and `Move File: a -> b` headers of a V4A patch, read with Unicode whitespace) of `local/config.php`, the configure tool's PHP, anything under `lib/` or any hook, matched on the path as written and on its real path; and a terminal or code write naming one of those files. Blocked: `pikkumies configure undo`, the person's own shell command. In an agent started by an agent (`PIKKUMIES_DEPTH` 2 or more) every question is a block ([ADR-0020](../../../../docs/adr/0020-deletes-need-the-users-approval.md)). Fails closed: a crash, a timeout, a regex engine error or a payload it cannot read blocks the call. A safety prompt, not security (AGENTS.md): a key or command built at run time, a shell write through a symlinked directory or a bare `config.php` from inside `local/` is out of its sight.
