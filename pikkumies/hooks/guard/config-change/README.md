# config-change

The check for Pikkumies' own settings ([ADR-0059](../../../../docs/adr/0059-settings-tiers-free-asked-and-the-persons-own.md)). The agent changes a setting with the `pikkumies-configure` tool. Changes that tighten something, or that are harmless either way (the agent's name, turning a safety hook back on), go through without a question. Changes that loosen something, cost credits, stop scheduled jobs or delete history (another model, turning off a tool category and its rules, hiding the low-credits notice, the scheduled-job ticker either way, turning search rewording off, a shorter session history, following unreleased code) go to the orchestrator's ask policy first, naming the setting, its old and new value and what the change does: it runs when the user's own words already asked for exactly this, and otherwise is blocked until the user says yes in the chat ([ADR-0073](../../../../docs/adr/0073-no-questions-no-deferrals-one-reviewed-exception.md)). Turning a safety layer off is the person's own: the tool and `Config::set` refuse it and say how the person does it.

The `rule_key` (the same setting from the same old value to the same new one) is used to merge two units' questions into one, not to remember a past answer.

Changes past the plain tool command are asked about with the whole command, because nothing in them is checked: a command or code that names a setting with an asked direction next to `set` or `apply`, `Config`, `ConfigureChange` or `ConfigureSettings` called directly, a `PIKKUMIES_CONFIG` overlay, and edits of `local/config.php` and of the files that decide what the agent may change (the configure tool, `lib/`, the hooks), by the file tools (a V4A patch's file headers and a symlinked directory too), the shell or code. `pikkumies configure undo` is blocked: it is the person's own shell command, which asks them on their terminal.

It is a safety prompt, not a security boundary: the agent runs as the same user and could edit the file some way this hook does not see; the person owns the file and can change anything in it.
