# pre-edit-copy

A copy of a small file as it was, taken just before the agent rewrites it ([ADR-0099](../../../../docs/adr/0099-backup-safety-layer.md)). It runs on `pre_tool_call` next to [guard-destructive](../guard-destructive/README.md) and [fileops-check](../fileops-check/README.md), and it never blocks or asks.

- **What counts as a rewrite:** Hermes' `write_file` and `patch` (also every file a V4A patch names), and in a `terminal` command `sed -i` (or `--in-place`), a `>`, `>|` or `&>` redirect, and `truncate`. An append (`>>`) and `2>&1` are not rewrites.
- **Which files:** existing regular files of at most 1 MiB that this account owns. Root and sudo follow the same rule: as uid 0 any owner's file is copied, and a `sudo sed -i` or `sudo truncate` of a file another account owns is copied through `sudo -n cat` (it never prompts; without passwordless sudo there is no copy). A redirect is done by the user's own shell, not by sudo, so `sudo cmd > /etc/x` is copied only when this account owns `/etc/x`. A new file has nothing to keep; a bigger one is left to `backup-safety snap` and real backups.
- **Where:** `local/tmp/pre-edit/<session id>/<the file's full path>`, a tmp folder under the account's quota that no other account can open, see or fill (`pikkumies/lib/LocalTmp.php`). Every folder must be this account's own with no access for anyone else (one this account left open is closed first), or nothing is copied and the agent gets one note that copies are off.
- **Whole copies only:** the file opened must be the regular file that was checked (same device and inode); at most 1 MiB is read; the copy is written as `<name>.part` with `x` (never over an existing name or through a planted symlink), and renamed only when every byte of the opened file arrived and the file closed cleanly. Files are 0600. The same content is kept once; a later different version gets a time suffix. At most 50 MB per session, counting the bytes really copied.
- **Telling the user:** the first copy of a session leaves one hook note for the agent with the folder, so it can say where an edit can be undone from. Then session folders older than 7 days are removed (only this account's own files, links never followed).

It fails open (3 s). The copy lives on this machine: it undoes a bad edit, it is not a backup. Real backups are the [backup-safety](../../../tools/backup/backup-safety/README.md) unit's subject.
