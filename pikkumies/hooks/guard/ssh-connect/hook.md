---
name: ssh-connect
event: pre_tool_call
description: Every SSH connection the agent makes says why (# intent:), and the person's SSH allow and deny lists decide where; hosts on neither list, routes it cannot follow and writes to ~/.ssh/config go through the orchestrator's ask policy ([ADR-0073](../../../../docs/adr/0073-no-questions-no-deferrals-one-reviewed-exception.md)).
failClosed: true
timeout: 5
---
Reads `terminal` commands and `process_manage` input (ssh, autossh, mosh, sftp, ssh-copy-id, ssh-keyscan, scp, rsync, sshfs, git with an SSH remote, behind sudo, env, timeout and similar wrappers, inside `sh -c`, `su -c`, `eval`, `watch`, `$(...)` and text piped into a shell), `execute_code` code and the `write_file`/`patch` paths (a V4A patch's headers too, `lib/PatchPaths.php`). Blocks, in order: a call or host it cannot read (a variable, substitution or glob in the host, an ssh option it does not know, a numeric address that is not a plain dotted quad); SSH from `execute_code`; any name on `ssh.deny` (the host typed, `-o HostName`, every `-J`/ProxyJump/`-W` hop and a ProxyCommand's ssh hop); a connection without `# intent: <why>` in the command and none stated for that host earlier in the session; with `ssh.blockUnknown`, a name not on `ssh.allow` or a route it cannot follow. Goes to the ask policy (`rule_key` `pikkumies-ssh:<sha1 of the command>`): names not on `ssh.allow`, routes it cannot follow (`-F <file>`, `-S`, ControlPath, a ProxyCommand without an ssh hop, `rsync -e` or `mosh --ssh` without ssh, `GIT_SSH_COMMAND`, `GIT_SSH`, `RSYNC_RSH`, `core.sshCommand`) and writes to `~/.ssh/config`; a question that is not `HookUnits::approveShown()`, or whose command holds control or direction characters, is a block, and in an agent started by an agent every question is a block. Lists come from `local/config.php` without the overlay (`lib/SshLists.php`). Fails closed: a crash, a timeout, a regex engine error or a payload it cannot read blocks the call ([ADR-0068](../../../../docs/adr/0068-ssh-connections-need-a-stated-intent-and-the-persons-allow-and-deny-lists.md), [ADR-0020](../../../../docs/adr/0020-deletes-need-the-users-approval.md), [ADR-0030](../../../../docs/adr/0030-hooks-as-units-run-by-one-orchestrator.md)).
