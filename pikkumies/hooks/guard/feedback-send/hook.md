---
name: feedback-send
event: pre_tool_call
description: Asks the user in Hermes' approval prompt before /feedback is sent, saying first where it goes and what goes; blocked with approvals off or in an agent started by an agent; the other forms of a feedback send it can see are blocked.
failClosed: true
timeout: 3
---
Reads `tool_name` and `tool_input`. A terminal command that is exactly `php <this Pikkumies' feedback.php> send <id>`, the path absolute (or `~/`, expanded with HOME) and canonical, gets `approve`. The message (`tools/system/feedback/FeedbackPrompt.php`) opens with where it goes and what goes: the user's text, the conversation transcript (whole, its newest 1.5 MB, or none) and system information (model, provider, folder, versions), to Pulsed Media at pikkumies.mcx.fi, locked and linked to the account; then the size, the file holding all of it and the start of the text, on one line with quotes escaped; the whole message passes `HookUnits::approveShown()` (at most `APPROVE_SHOWN` characters), and one that cannot fit is a block. `rule_key` is `pikkumies-send:<id>`, the draft's own sha256 prefix (32 hex digits), so one answer covers one payload. With `HERMES_YOLO_MODE` set (approvals off) or at `PIKKUMIES_DEPTH` 2 or more, the plain send is blocked and the message gives the command for the user to run in their own terminal (ADR-0056 amendment 2026-10-19). Blocked, in a terminal command, `execute_code` code, `process_manage` input, `write_file` or `patch` content and `cronjob_manage` input: a feedback path followed by `send` (only the word right after the path counts, so a draft whose text says "send" runs), `FeedbackSend` or `FeedbackDraft` with the word send, and a feedback path with shell expansion (`$ * ? [` or a backtick) and the word send. Also blocked: a draft that is missing, changed since it was made, or already sent ([ADR-0056](../../../../docs/adr/0056-feedback-what-pikkumies-sends-to-pulsed-media.md)). A safety prompt that catches the agent's own and casual sends, not a security boundary: an agent steered by text it reads can still run the sender some other way, as it could run curl (AGENTS.md). The payload is sealed to Pulsed Media either way.
