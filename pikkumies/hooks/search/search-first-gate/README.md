# search-first-gate

Search first ([ADR-0011](../../../../docs/adr/0011-documentation-sources-and-search-first.md), [ADR-0028](../../../../docs/adr/0028-search-first-every-turn-and-a-light-model-for-hooks.md)). Until the agent has run `tools/memory/pikkumies/pikkumies.php search` in the session, tool calls that act are blocked with the command to run. Reading files, asking the user and the memory tool's `search`, `list` and `sources` verbs stay allowed; only the memory search opens the gate ([ADR-0037](../../../../docs/adr/0037-wiki-and-kb-tool-units.md)). A plain `system-status` `show`, `account` or `health` call also runs while the gate is closed: it is the live answer for this account's own figures and state, so it does not wait for a search, and it opens nothing ([ADR-0058](../../../../docs/adr/0058-account-status-verb-and-live-figures-before-search.md), [ADR-0066](../../../../docs/adr/0066-system-status-health-one-answer-to-is-it-down.md)). Its `logs` verb and any chained or substituted command still wait. Lessons come before documentation ([ADR-0043](../../../../docs/adr/0043-lessons-before-documentation.md)): reading or searching `local/docs-cache/`, and the `wiki` and `kb` tools' `search` and `list`, wait for the memory search.

- Only one plain call of the search counts ([ADR-0038](../../../../docs/adr/0038-plain-search-command-config-overlay-live-source-check.md)): nothing may follow it but `2>&1` or `2>/dev/null`, then or instead one pipe into `head` or `tail`. A blocked command that contains the search is told it was not counted.
- The search touches one marker file per session under `local/state/search-first/` (files older than 7 days are removed).
- `search-first` touches `<marker>.armed` when a later turn asks something new; the gate stays closed until a search is newer.
- `searchFirst.disabled` in `local/config.php` turns it off.

It fails open: if it errors or times out the call runs. The agent's user can write the marker files, so this is a habit prompt, not a security boundary.
